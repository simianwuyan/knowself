# 论文导入分析 + 引文学习路线 + 知识点对比 实施方案

## Context

用户核心学习场景是**读论文**：希望直接给出一篇将要学习的论文，AI 分析罗列其中的知识点并标注掌握度；论文自带的参考文献也应成为学习路线的延伸（比通用清单更细）；另需知识点**异同对比**辅助辨析。

已验证的关键前提：**OpenAlex 支持按 DOI / arXiv ID / 标题取论文元数据**（实测 DDPM 论文 10.48550/arxiv.2006.11239 → 标题/作者/年份/摘要倒排索引/**71 条参考文献 ID** 全部可得，且 CORS 直连、免费无 Key）——引文路线基于真实引文数据构建，而非 AI 凭空猜测。

已确认决策：提取的知识点**融入当前学习计划**（自动连入图谱，节点带来源徽章）；对比采用**手动勾选 2~4 个节点**生成、可保存回看。

## 功能设计

### A. 论文导入（在项目详情页）

1. 入口：项目详情页「📄 从论文提取知识点」→ 弹出导入对话框（新组件 `PaperImportDialog.tsx`）
2. **智能识别输入**（单个输入框）：DOI（10.xxx/…）、arXiv ID（如 2006.11239）、论文标题、或直接粘贴摘要/正文片段
   - 识别为链接/标题 → 调 OpenAlex `fetchPaperMeta()`（新增于 `src/literature.ts`）：取标题/作者/年份/摘要（倒排索引重建）/参考文献（referenced_works 批量解析为题录，最多 30 篇）
   - 识别为长文本 → 直接作为分析素材
3. 确认卡展示（标题、作者·年份·期刊、摘要、参考文献 N 篇）→「AI 提取知识点」
4. AI 分析（`shared/prompts.ts` 新增 prompt + `shared/ai-client.ts` 的 `analyzePaperAI`）：输出 JSON——
   - `paperNode`：论文本身（kind=paper，描述其贡献与为什么必读）
   - `nodes`：8~20 个读懂该论文所需的细粒度概念/模型/公式节点（互相间有依赖）
   - `keyRefs`：从真实参考文献中挑 3~6 篇必读引文 + 一句话理由
5. **合并进当前计划**（双模式各自实现，逻辑一致）：
   - 概念节点（mastery=unknown，带 `fromPaper` 来源）追加到 `project.nodes`
   - keyRefs 生成 paper 节点（prereqs 为空，可再被细化）
   - paperNode 的 prereqs = 概念节点 + keyRef 节点（即：读懂论文←概念+引文）
   - paperNode 附带 `refs[]` 完整参考文献题录
   - 按 name 去重：已存在的同名节点跳过
6. NodeSheet 增强：paper 节点显示「参考文献（N）」区块，每条可 **＋加入学习路线**（复用现有 `addNode` 建 paper 节点）/**🔍 OpenAlex 检索**（跳 LiteraturePanel）

### B. 知识点异同对比

1. 「全部清单」Tab 加「选择对比」模式：勾选 2~4 个节点 → 底部浮条「对比 (n)」
2. `compareNodesAI`（shared）：输入节点 name/description/kind → 输出结构化文本：共同点 / 关键差异 / 联系与依赖 / 常见混淆点 / 各自适用场景
3. 结果弹窗（新组件 `ComparisonSheet.tsx`）→「保存到项目」
4. `Project.comparisons[]` 持久化；项目菜单加「对比记录」列表，可回看/删除

### C. Mock

`shared/mock.ts` 补 `mockAnalyzePaper`（按输入标题生成示例节点+keyRefs）与 `mockCompare`，无 Key 也能全流程体验。

## 数据模型（向后兼容，旧数据缺省字段即可）

- `KnowledgeNode` + `fromPaper?: string`、`refs?: {title, year?}[]`（仅 paper 节点）
- `Project` + `comparisons?: {id, nodeNames: string[], text, createdAt}[]`

## 后端改动（`server/index.js` + Backend 接口四处实现）

- `POST /api/projects/:id/analyze-paper`（{input} → OpenAlex 元数据在**前端**获取后随请求发送题录+摘要，后端只管 AI 与合并落库）
- `POST /api/projects/:id/compare`（{nodeIds} → AI 对比文本，不落库）
- `POST /api/projects/:id/comparisons` / `DELETE .../comparisons/:cid`（保存/删除对比记录）
- `src/backend/types.ts`（Backend 接口）、`rest.ts`、`server.ts`、`local.ts`、`api.ts` 门面同步扩展
