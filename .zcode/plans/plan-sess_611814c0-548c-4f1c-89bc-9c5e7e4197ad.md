# KnowSelf — 科研学习路线规划工具 实施方案

## Context（背景）

科研入门一个新方向时，不知道该学什么、按什么顺序学。本项目在空目录 `D:\WADINE\project\entertain\knowself` 从零构建一个工具：用户输入**科研方向**，调用 AI（OpenAI 兼容接口）生成该方向所需的**知识清单**（含先后依赖、重要程度、推荐资料、预计耗时）；用户逐项标注**掌握程度**；系统自动过滤已掌握项、按依赖关系拓扑排序，生成**分阶段学习路线**。

已确认的决策：**手机上使用**（做成移动端优先的 Web 应用，电脑上跑服务、手机浏览器经局域网访问）＋ **OpenAI 兼容接口**（可配 Base URL / Key / 模型名）＋ **React + TypeScript + Vite** ＋ **分阶段学习路线**呈现。

## 架构

- **前端**：React 18 + TypeScript + Vite，Tailwind CSS v4（`@tailwindcss/vite` 插件），移动端优先（390px 设计宽，兼容桌面）
- **后端**：Node + Express（端口 3000），职责：① 代理 AI 调用（Key 不暴露给浏览器、规避 CORS）② JSON 文件持久化（`data/` 目录）③ 静态托管前端构建产物
- **数据集中存电脑端**：手机、电脑访问同一份数据；无数据库，每个项目一个 JSON 文件
- **启动脚本**：`npm run dev`（开发，concurrently 同时起 Vite 与 Express）；`npm run build && npm start`（生产，单进程）；服务启动时在控制台打印本机局域网 IP，供手机访问 `http://<PC内网IP>:3000`
- **PWA manifest**：手机「添加到主屏幕」后有类原生 App 图标体验（不做离线 Service Worker，AI 调用本身需联网）

## 数据模型

```ts
type Mastery = "unknown" | "partial" | "mastered";
interface KnowledgeNode {
  id: string; name: string; description: string;
  importance: "core" | "recommended" | "extension";  // 核心/进阶/拓展
  prereqs: string[];            // 存其他节点 name（AI 返回时以 name 引用）
  estHours: number;
  resources: { title: string; type: "book"|"course"|"paper"|"tutorial"; note?: string }[];
  mastery: Mastery;
}
interface Project { id: string; title: string; direction: string; background?: string; goal?: string;
                    summary: string; nodes: KnowledgeNode[]; createdAt: number; }
// 持久化：data/projects/<id>.json、data/settings.json（baseUrl、apiKey、model、useMock）
```

## 后端 API

- `GET/PUT /api/settings`、`POST /api/settings/test`（测试 AI 连通）
- `GET /api/projects`、`POST /api/projects`（保存方向/背景/目标草稿）、`GET/DELETE /api/projects/:id`
- `POST /api/projects/:id/generate`（调 AI 生成知识清单，解析校验后落库；超时 120s）
- `PATCH /api/projects/:id/nodes/:nodeId`（改掌握状态/内容）、`DELETE` 节点、`POST` 手动加节点
- `POST .../nodes/:nodeId/expand`（AI 把该节点细化为子知识点）、`POST .../resources`（AI 推荐更多资料）

## AI 集成

- 统一走 `server/ai.js`：Node 18+ 内置 fetch 调 `<baseUrl>/chat/completions`，OpenAI 兼容格式
- 生成清单用严格 Prompt：要求只输出 JSON（15–30 个节点，含 name/description/importance/prereqs/estHours/resources；prereqs 必须引用清单内其他节点名，禁止循环依赖）；`response_format: json_object` 优先，不支持则去除 ```json 围栏后解析；解析失败带错误重试 1 次
- **Mock 模式**：未配置 Key 或设置 `useMock: true` 时返回预置示例数据（如「扩散模型图像生成方向」），保证无 Key 也能跑通全流程
- JSON 解析容错工具：剥围栏、截取首尾大括号、JSON.parse 校验 schema

## 学习路线算法（`src/route.ts`，前端计算）

1. 过滤掉 `mastered` 节点（`partial` 保留并标「需复习」）
2. prereq name → id 归一化匹配（忽略大小写/空白，匹配不到的忽略）
3. Kahn 拓扑排序；若 AI 产出环，从重要度最低的节点断边并记警告
4. 按「最长路径深度」分层 = 阶段 1、2、3…；阶段内 core 优先、按 estHours 降序
5. 统计：进度 = 已掌握节点占比、剩余预计总时长

## 界面（移动端优先，5 个页面）

1. **项目列表** `/`：项目卡片（标题、进度条、节点数、剩余时长）、新建 FAB、设置入口
2. **新建向导** `/new`：研究方向*、已有背景、学习目标 → 「AI 生成」loading → 跳详情
3. **项目详情** `/project/:id`：顶部进度统计；Tab「学习路线 | 知识清单」；路线按阶段分组，节点卡片带 掌握/部分/未掌握 三态切换；支持导出 Markdown、重命名、删除、AI 重新生成
4. **节点详情底部抽屉**：描述、前置项（可点跳转）、资料列表、「AI 细化为子知识点」「AI 推荐更多资料」
5. **设置页** `/settings`：Base URL / API Key / 模型名 / Mock 开关 / 测试连接
